# CodeAlpha Cloud Computing Internship - Task 4: AI Chatbot

A high-performance, serverless, cloud-native **AI Chatbot Widget** built entirely with semantic HTML5, modern layout CSS3, and high-precision Vanilla JavaScript. This application functions as a lightweight commercial assistant integrated seamlessly into a client web interface with **zero heavy backend dependencies**.

---

## 🚀 Key Technical Features

* **Intelligent Scoring Matcher Engine:** Replaced basic word matching with a keyword-semantic pattern scoring NLP algorithm. The engine tokenizes inputs, removes punctuation, and scores user sentences to surface the highest-confidence commercial intent dynamically.
* **Asynchronous Networking Life Cycles:** Simulates cloud architecture latency by injecting programmatic delay buffers (600ms - 1100ms) paired with functional CSS typing state indicators and loading dots.
* **Context-Aware Suggestion Pills:** Features interactive, quick-reply suggestion chips that dynamically rebuild and refresh their context paths based on the conversational node state.
* **Cross-Component UI Bridging:** Linked the primary website CTA button (`Explore Console`) straight into the widget trigger node to automatically expand the chat instance and pull active view focus smoothly.
* **100% Client-Side Efficiency:** Runs with a zero-infrastructure footprint, ensuring lightning-fast client loading boundaries and seamless execution over standard internet protocols.

---

## 🛠️ Technology Stack Used

* **Frontend Structure:** HTML5 (Semantic Layout Rules)

## 💻 Quick Local Deployment Instructions

Follow these steps to run and test the AI Chatbot application locally on your workstation:

1. **Clone or Download the Codebase:**
   Clone this repository to your computer or copy the project files (`index.html`, `style.css`, and `script.js`) into a dedicated folder.

2. **Open the Project Folder:**
   Launch **Visual Studio Code**, navigate to `File` > `Open Folder...`, and select your project workspace.

3. **Launch the Application Interface:**
   * Right-click inside `index.html` and click `Open with Live Server` (if the extension is installed).
   * Alternatively, locate your local folder inside your computer's File Explorer/Finder and **double-click** `index.html`. It will execute instantly in your web browser.

4. **Trigger Interactivity Triggers:**
   Click the blue floating chat widget icon in the bottom-right corner (or click the main screen `Explore Console` CTA button) to execute the conversational engine pipeline.
